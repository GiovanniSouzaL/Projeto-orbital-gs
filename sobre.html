O que é a ÓRBITA?

A ÓRBITA é uma plataforma de inteligência satelital desenvolvida como projeto da Global Solution 2026/1 da FIAP, no curso de Análise e Desenvolvimento de Sistemas.

O objetivo é pegar os dados que já existem nos satélites da NASA, ESA e INPE e entregá-los de forma útil para quem realmente precisa — agricultores, gestores de crise e planejadores ambientais.

O projeto foi construído do zero em HTML, CSS e JavaScript puro, sem nenhum framework externo, como exige a disciplina de Front-End Design Engineering.
